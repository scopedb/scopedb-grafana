# Changelog

## 0.2.0
- General-purpose ScopeDB connector with no application-table dependency.
- Catalog discovery, ScopeQL code editor, field/macro suggestions and query templates.
- Safely formatted Dashboard variables, query-variable labels/values and All/multi-select support.
- Adaptive and fixed time buckets, explicit range/interval macros and labeled time-series frames.
- Per-instance concurrency limits, API error classification and query diagnostics.
- Portable Getting started dashboard; Bluesky and historical fixtures are opt-in examples.
- Preserves the plugin ID, credentials and legacy v1 Table queries.

## 0.1.0
- Internal Grafana OSS 13.1.0 / Linux amd64 integration.
- ScopeQL Table queries through the official ScopeDB Go SDK.
- Secure API key configuration, health check, time filter macro, timeout and cancellation.
